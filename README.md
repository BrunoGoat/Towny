# Towny

![Un pueblo de Towny al atardecer](doc/pueblo.png)

Una app de hábitos donde cada vez que cumplís, construís.

Cada logro agrega una pieza a tu pueblo. Si dejás de venir, el pueblo no desaparece: se apagan sus luces. Cuando volvés, vuelve a la vida.

Sin rachas. Sin castigos. El objetivo no es no fallar, es volver.

Empezás con un hábito y desbloqueás más a medida que lo sostenés.
