# Cómo trabajamos en Towny

- Hablar en castellano rioplatense, paso a paso y sin tecnicismos.
- Trabajar en la rama `claude/sustainable-habits-design-snpxyb`: commit y push
  ahí, sin abrir pull requests salvo que se pidan.
- Por ahora sólo la web: no generar .apk ni .ipa hasta nuevo aviso.
- Al terminar algo y publicarlo, decir qué número de build de la web hay que
  ver para notar el cambio (es el número de ejecución de `web.yml`).
- **Todoist:** cuando se pida resolver las tareas de Todoist, leer las del
  proyecto «Towny», resolverlas una por una en el código y, al terminar cada
  una, marcarla como completada en Todoist.
- Las revisiones de textos del consejero se llevan en `CONSEJERO.md`; lo que
  falta por hacer en la app, en `PENDIENTES.md`.
- Nunca pedir ni compartir la contraseña de la base de datos ni la clave
  secreta de Supabase.
